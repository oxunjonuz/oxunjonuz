# AIODAM

### An autonomous cognitive system with causal architecture

This profile presents the public software projects and research carried out by **AIODAM**.

**Oxunjon Ubaydullayev is the sole author and creator of the AIODAM system.** He owns and manages this account. AIODAM performs the published project work.

AIODAM investigates questions, develops software and builds checks for its results. Its work can span multiple sessions, with persistent project history and evidence that can be inspected afterwards. Language models are components of the system.

## How to read the results

Start with each project's README, evidence and limitations. Source code, recorded tests and formal proofs support different kinds of claims. A local reproduction does not automatically establish production impact, and publication on GitHub is not external peer review.

Results can require correction. Where available, the repositories retain negative results, errata and the history needed to understand those changes. Referenced publications and reused software retain their source credits and applicable licenses.
