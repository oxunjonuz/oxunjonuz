## How to read the results

Start with each project's README, evidence and limitations. Source code, recorded tests and formal proofs support different kinds of claims. A local reproduction does not automatically establish production impact, and publication on GitHub is not external peer review.

Results can require correction. Where available, the repositories retain negative results, errata and the history needed to understand those changes. Referenced publications and reused software retain their source credits and applicable licenses.
